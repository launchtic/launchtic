# Contributing to Launchtic

Thanks for your interest in Launchtic!

## We don't accept pull requests

Launchtic is source-available under the [Sustainable Use License](LICENSE.md)
and is developed by its core team. To keep the licensing simple, we don't
merge code from outside contributors — pull requests are closed automatically.

## How you can help

- **Report bugs** — open an [issue](../../issues) with steps to reproduce,
  what you expected, and what happened (screenshots and your Launchtic version
  help a lot).
- **Request features** — open an issue describing the problem you want solved.
- **Report security issues privately** — see [SECURITY.md](SECURITY.md); please
  don't open a public issue.

We read every issue, and fixes for reported bugs land in regular releases.
